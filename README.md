# EpiModeling
Tutorials for using the EpiModel software platform for research, designed for EpiModel Research Lab members but potentially helpful for others. Primary materials will be posted and updated on the [Wiki Page](https://github.com/EpiModel/EpiModeling/wiki) for this repository.

This repository also holds files used by the wiki:

- `sbatchExample/`: a small example of passing parameters to an R script with `sbatch` on the HPC, used in [Running R with a batch job with sbatch](https://github.com/EpiModel/EpiModeling/wiki/Running-R-with-a-batch-job-with-sbatch).
- `assets/`: images and other files embedded in wiki pages.
